# Hillary's Jewelry Boutique

An ecommerce jewelry website built using PHP, HTML, CSS, and MySQL.

## Features

- Product catalog
- Customer registration
- Customer login
- Shopping cart
- Checkout form
- Order confirmation
- MySQL relational database

## Technologies Used

- PHP
- HTML5
- CSS3
- MySQL

## Database Setup

1. Open MySQL
2. Run:

```sql
CREATE DATABASE jewelry_store;
USE jewelry_store;
SOURCE ecommerce_database.sql;
```

## Run The Website

1. Install XAMPP
2. Move project folder into:

htdocs

3. Start Apache
4. Visit:

http://localhost/hillary-jewelry-boutique/
